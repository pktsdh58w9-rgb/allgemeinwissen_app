# GoKnowledge

Wissens-Reels für Safari auf dem iPhone: senkrecht wischen, Thema antippen oder nach links wischen, in ~1 Minute lesen.

- `index.html`, `styles.css`, `app.js` – die App (reines HTML/CSS/JS)
- `data/cards.json` – alle Karten (Inhalte + Wikimedia-Commons-Bilder)
- `SPEC.md` – abgestimmte Spezifikation
- `design/` – Design-Entwürfe

Lokal testen: `python3 -m http.server` und `http://localhost:8000` öffnen.
